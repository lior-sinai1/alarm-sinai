# מצלמות — התקנה על ה-Mini PC

## שלב 0 — דיסק מוצפן להקלטות ולתמונות הפנים

הסקריפט `00-prepare-secure-disk.sh`:
- **מוחק** את הזיכרון הפנימי `mmcblk0` (ה-Windows הישן). הדיסק און קי של המערכת לא נוגעים בו.
- יוצר עליו מחיצה מוצפנת (LUKS2) שנפתחת אוטומטית בהדלקה דרך ה-TPM.
- מחבר אותה ל-`/srv/secure`, ואת `/srv/secure/frigate` לתיקייה שה-Add-on של Frigate ישמור אליה.
- אם הפתיחה נכשלת — Frigate פשוט לא יקליט; Home Assistant והאזעקה ממשיכים לעבוד, ושום דבר לא נכתב בטעות לדיסק און קי.

### לפני שמריצים — הקשחת BIOS (מומלץ, 5 דקות)
ההצפנה מגינה על הדיסק, אבל הוא מולחם ללוח — גנב ייקח את כל המחשב. כדי שלא יוכל
לעלות ממערכת אחרת ולקרוא את הדיסק:
1. היכנס ל-BIOS (בדרך כלל `Del` או `F2` בהדלקה).
2. הגדר **סיסמת מנהל ל-BIOS** (Administrator / Supervisor password).
3. בסדר האתחול (Boot) השאר **רק את הדיסק און קי הנוכחי**, וכבה אתחול מ-USB אחר / רשת אם יש אפשרות.
4. שמור וצא.

**חשוב לעשות את זה לפני הסקריפט** — שינויים מסוימים ב-BIOS משנים את מצב ה-TPM ואז הפתיחה האוטומטית תיכשל
(אפשר לתקן עם סיסמת השחזור, ראה למטה).

### הרצה
1. העתק את `00-prepare-secure-disk.sh` למחשב — ב-MobaXterm גרור אותו לחלון הקבצים משמאל (לתיקייה `/home/lior`).
2. בטרמינל:
   ```bash
   su -
   sed -i 's/\r$//' /home/lior/00-prepare-secure-disk.sh
   bash /home/lior/00-prepare-secure-disk.sh
   ```
3. הסקריפט יבקש:
   - להקליד `ERASE` לאישור המחיקה.
   - **סיסמת שחזור** (פעמיים) — **כתוב אותה על נייר ושמור מחוץ למחשב.**
   - את סיסמת השחזור עוד פעמיים (פתיחה + קישור ל-TPM).
4. בסוף הוא בודק פתיחה דרך ה-TPM בלבד ומציג את הדיסק המחובר.

### בדיקה אחרי הפעלה מחדש
```bash
reboot
# אחרי שעלה, שוב su - ואז:
systemctl status secure-storage --no-pager
findmnt /var/lib/homeassistant/media/frigate
df -h /srv/secure
```
צריך לראות `active (exited)` ושני החיבורים. שלח לי את הפלט.

### אם הפתיחה האוטומטית הפסיקה לעבוד (למשל אחרי שינוי ב-BIOS)
```bash
su -
cryptsetup open /dev/mmcblk0p1 secure      # סיסמת השחזור
systemctl start secure-storage
clevis luks regen -d /dev/mmcblk0p1 -s 1   # קישור מחדש ל-TPM
```
